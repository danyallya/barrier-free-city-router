# Roadmap

1. Foundation — base shell is present; preparation PR #6 and day-1 PR #7 are open. The feature branch includes the npm lockfile.
2. First domain slice — local route-segment observations with a six-hour freshness window; no route engine or map provider.
3. Durable workflow — PostgreSQL migrations, history, export and deletion.
4. Offline workflow — local writes, outbox, idempotency and conflict UX.
5. Release readiness — access control, audit, accessibility, backups, threat review and deployment.

Thin MVP estimate after foundation: 14-24 focused engineering days; excludes external approval.
